RetireSafe Security Policy

Updated October 2026

1. Hosting and architecture

RetireSafe is built on Atlassian Forge. Its application logic runs within the Atlassian Forge platform and persistent app data is stored using Atlassian Forge hosted storage.

2. Jira permissions and behavior

RetireSafe is designed for read-only Jira administration analysis. Its purpose is to inspect project activity, unresolved work, configuration dependencies, and retirement-readiness signals. RetireSafe does not intentionally delete, archive, or modify Jira projects or Jira configuration.

3. External services

RetireSafe does not expose a public remote REST API for customer integrations and does not rely on a separate RetireSafe-hosted backend database for Jira customer data.

4. Data protection

Persistent app data is stored through Atlassian Forge hosted storage. RetireSafe is designed to minimize collection and storage of End-User Data to what is needed for app functionality.

5. Vulnerability reporting

If you believe you have discovered a security issue in RetireSafe, please report it using the security contact published on the RetireSafe Atlassian Marketplace listing. Please include enough detail to reproduce and assess the issue, but do not include unnecessary customer data or secrets.

6. Responsible disclosure

We ask security researchers to avoid privacy violations, service disruption, destructive testing, or accessing data that does not belong to them. We will review good-faith security reports and work to address confirmed issues.

7. Changes to this policy

This security policy may be updated as RetireSafe evolves.
